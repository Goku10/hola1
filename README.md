# Español MYP4 — Spanish Practice Dashboard

An interactive practice dashboard built for an IB MYP4 Spanish Acquisition student (Phase 1-2), covering all four IB assessment criteria:

- **Vocabulary** — flashcards + quizzes across 6 topics (family, food, school, routine, house, free time)
- **Grammar** — ser vs. estar, present tense -ar verbs, possessive adjectives
- **Listening** (Criterion A) — audio comprehension via browser text-to-speech
- **Speaking** (Criterion C) — pronunciation practice using browser speech recognition
- **Writing** (Criterion D) — writing prompts with self-check checklist
- **Progress** — session-based skill tracking across all criteria

## Usage

Open `index.html` directly in a browser, or enable **GitHub Pages** (Settings → Pages → Deploy from branch → main → / root) for a shareable link.

## Notes

- Speech recognition requires Chrome or Edge with microphone permission.
- Progress resets each session (no backend/storage) — a lightweight practice tool, not a gradebook.
